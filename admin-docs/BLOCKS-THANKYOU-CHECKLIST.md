# Thank-you checklist block

[← Back to Gutenberg Blocks overview](BLOCKS.md)

## What this block is for

Post-event thank-you checklist for couples tracking notes/gifts.

**Shortcode equivalent:** `[wgrsvp_thankyou_tracker]`

**Block name:** `wedding-party-rsvp/thankyou-checklist`

---

## Sidebar settings

| Setting | Default | What it does |
|---------|---------|--------------|
| **Public** | Off | When enabled, exposes the public-mode attribute used by the shortcode/block for shared checklist views |

---

## Tips

- Keep the checklist on a private or password-protected page if it contains personal gift notes.
- For guest-facing thank-you *status* after RSVP, use Pro’s **Household RSVP status** block instead.
