# Wedding RSVP Form block

[← Back to Gutenberg Blocks overview](BLOCKS.md)

## What this block is for

Shows the full guest RSVP flow (lookup, household responses, meals when configured).

**Shortcode equivalent:** `[wedding_rsvp_form]`

**Block name:** `wedding-party-rsvp/rsvp-form`

---

## Sidebar settings

No custom attributes. Form fields and options come from **Wedding RSVP → Settings** (and Pro modules when active).

---

## Tips

- Use one primary RSVP page so guest links stay consistent.
- After RSVP, set a Redirect URL (Settings) if you use a thank-you page.
- With Pro, add **Household RSVP status** on the thank-you page.
