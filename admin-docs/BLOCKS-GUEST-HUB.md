# Guest Hub block

[← Back to Gutenberg Blocks overview](BLOCKS.md)

## What this block is for

Personalized RSVP summary for guests after they submit (schedule highlights, travel, next steps depending on configuration).

**Shortcode equivalent:** `[wgrsvp_guest_hub]`

**Block name:** `wedding-party-rsvp/guest-hub`

---

## When to use it

- Thank-you / post-RSVP page
- A dedicated “your wedding info” page for returning guests

---

## Sidebar settings

No custom attributes. Hub sections are controlled by plugin settings (and Pro travel/itinerary modules when present).
