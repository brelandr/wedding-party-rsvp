## What this block is for

Public wedding schedule / itinerary for guests.

**Shortcode equivalent:** `[wgrsvp_itinerary]`

**Block name:** `wedding-party-rsvp/itinerary`

Configure itinerary items in the Wedding RSVP admin (schedule / itinerary settings). Pro may extend schedule features when licensed.
