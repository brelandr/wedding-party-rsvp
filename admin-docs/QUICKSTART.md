# Quick Start — Wedding Party RSVP (Free)

## Install

1. Install **Wedding Party RSVP** from WordPress.org or upload the zip.
2. Activate the plugin.
3. Open **Wedding RSVP** in the admin menu.

## First steps

1. Add your event details under Settings.
2. Create or edit a page and insert the **Wedding RSVP Form** block (category **Wedding Party RSVP**).
3. Optionally add **Guest Hub**, **Guestbook**, **Guest itinerary**, **Travel & lodging**, or **Thank-you checklist**.
4. Share the RSVP page URL with guests.

## Upgrade path

**Wedding Party RSVP Pro** adds seating, email/SMS, photo gallery, e-invite, registry hub, budget tools, and more. When Pro is licensed, open **Wedding RSVP → Documentation** for the Pro hub.
